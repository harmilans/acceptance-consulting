# Acceptance Consulting — Pre-Screen Tool

A candidate pre-screen scoring tool: an instant rule-based score plus a full
narrative assessment generated by Claude (reads attached CV/essay PDFs directly).

## Project structure

```
index.html        the entire frontend (single file, no build step)
api/assess.js      Vercel serverless function — holds the real Anthropic API key
package.json
.env.example       template for local env vars (copy to .env for local dev)
.gitignore
```

## Deploy to Vercel (dashboard — easiest)

1. Push this folder to a GitHub repo.
2. Go to https://vercel.com/new and import that repo.
3. Before the first deploy (or right after), go to
   **Project Settings → Environment Variables** and add:
   - Key: `ANTHROPIC_API_KEY`
   - Value: your real key (starts with `sk-ant-...`)
   - Apply to: Production, Preview, and Development
4. Deploy. Vercel will automatically serve `index.html` at `/` and
   `api/assess.js` as a serverless function at `/api/assess`.

## Deploy via CLI (alternative)

```bash
npm install -g vercel
cd acceptance-consulting-app
vercel login
vercel env add ANTHROPIC_API_KEY     # paste your key when prompted
vercel --prod
```

## Local testing

```bash
cp .env.example .env      # then edit .env and paste your real key
vercel dev
```

This runs the same serverless function locally so you can test the AI
assessment flow before deploying.

## Notes on cost and safety

- The API key lives only in `api/assess.js`, read from `process.env`. It is
  never sent to or visible in the browser.
- `MODEL` and `MAX_TOKENS` in `api/assess.js` are fixed server-side on purpose,
  so a visitor can't request a more expensive model or a huge token budget.
- There's a basic payload-size guard, but **no real rate limiting yet**. Before
  sharing this publicly, add rate limiting (e.g. Vercel's Edge Config / Upstash
  Redis, or a simple per-IP counter) so the endpoint can't be hammered and run
  up your Anthropic bill.
- DOC/DOCX attachments are accepted by the UI but not parsed — only PDF and
  plain text are read by Claude in this version. Adding DOCX support means
  converting DOCX → text/PDF before the API call (e.g. with `mammoth` in the
  serverless function).
- The historical segment data and cohort multipliers in `index.html` are
  still illustrative/synthetic — swap them for Acceptance Consulting's real
  aggregated client outcomes before this becomes a real product.
